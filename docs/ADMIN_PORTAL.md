# School Administration Portal Documentation (`apps/admin`)

## Purpose
The Admin Portal is a separate, private enterprise application for authorized school administrators to manage student records, faculty profiles, admissions, academic schedules, fees, website CMS content, and system security.

## Admin Dashboard Modules
1. **Dashboard (`/`)**: Overview stats (students, faculty, pending admissions, fee revenue), quick action buttons, recent payment logs.
2. **Students (`/students`)**: Student registration, grade assignment, parent contact info, status management.
3. **Teachers (`/teachers`)**: Manage teacher profiles, assign subjects/departments, toggle Public Website Faculty visibility.
4. **Staff (`/staff`)**: Administrative and non-teaching personnel records.
5. **Admissions (`/admissions`)**: Review admission enquiries submitted via the public site, approve/reject applications, document verification.
6. **Academics (`/academics`)**: Class & section management, subject mapping, room allocations.
7. **Attendance (`/attendance`)**: Student & teacher daily attendance logs and monthly analytics.
8. **Examinations (`/examinations`)**: Exam timetables, term schedules, student marks entry, report generation.
9. **Fees (`/fees`)**: Fee structures per grade, record student payments, issue receipts, pending fee lists.
10. **Timetable (`/timetable`)**: Class timetables, teacher slots, period schedules.
11. **Events CMS (`/events-cms`)**: Publish/edit school events for the public website.
12. **Notices & News CMS (`/notices-cms`)**: Post circulars, announcements, and news articles.
13. **Gallery CMS (`/gallery-cms`)**: Manage photo albums and gallery uploads.
14. **Website CMS (`/website-cms`)**: Dynamic editor for Principal Message, Vision & Mission, History, Facilities text, Hero banners.
15. **Downloads CMS (`/downloads-cms`)**: Manage downloadable prospectus forms, syllabus PDFs, policy documents.
16. **Achievements CMS (`/achievements-cms`)**: Student, teacher, and school award records.
17. **Calendar Admin (`/calendar-admin`)**: Manage academic calendar dates and holidays.
18. **Enquiries Admin (`/enquiries`)**: Manage contact submissions sent from public site.
19. **Reports & Exports (`/reports`)**: Exportable PDF/CSV reports for admissions, attendance, fees, and academic records.
20. **System Settings (`/settings`)**: School name, logo URL, active academic year.
21. **Audit Logs (`/audit-logs`)**: Admin login activity log, IP addresses, modification history.
